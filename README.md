# DAADER

Three-language static legal website for daader.ir.

## Hosting

GitHub Pages, deploy from branch main and directory /docs. The docs/CNAME file binds daader.ir. docs/.nojekyll disables Jekyll processing. No dependencies or Actions workflow are required.

## Update

Run python3 build.py, then commit build.py and docs. CSS, JavaScript and assets are under docs/assets. WhatsApp opens +989123084826 directly from every page, including without JavaScript. Canonical URLs, language alternatives and sitemap use https://daader.ir.

The legal notes are introductory draft content for the owner to review.
